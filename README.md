## 🌐 Maternal Care AI Web Application

This repository contains the **Streamlit-based web application** developed as the deployment component of the Maternal Health Risk Prediction project. The application provides an intuitive interface for users to input clinical and demographic details and receive real-time predictions of maternal risk levels (high or low) using the trained machine learning model. It is designed to support early detection and decision-making, especially in resource-limited healthcare settings, by making the predictive system easily accessible and user-friendly.

👉 Explore the web app repository here: *(https://github.com/thamodya2001/MaternalCare-AI)*
